# Diferencias vigentes respecto de las capturas

La implementación actual **no es idéntica al 100 %** a los nueve PNG del usuario. La revisión nueva y verificable del 3 oct 2026 está en:

- [Matriz por pantalla y requisito](audit/01-design-traceability-matrix.md)
- [Informe de conformidad y validaciones](audit/03-conformity-report.md)
- [Preguntas que bloquean datos o capacidades](audit/04-open-questions.md)
- [Tareas pendientes](audit/02-task-index.md)

Principales diferencias: las capturas incluyen fotografías, videos, cuatro teléfonos activos, series históricas y cifras que la instalación actual no proporciona. La vista Python está limitada por `EXPOSE_SOURCE=false`; MPT figura offline; no hay API de historial de despliegue. Los cambios de composición disponibles ya se aplicaron en código, pero aún queda ajuste visual medible en TASK-001. No se utilizan valores ilustrativos de las capturas como datos de producción.
